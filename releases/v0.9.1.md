PureTube now checks for signed updates automatically on launch and every six hours.

- Settings shows the installed version, last successful check, and download progress.
- Update and restart verifies the installer signature before installing and reopening PureTube.
- Follows, library, watch history, and preferences stay on this PC across upgrades.
- The updater uses the public GitHub release feed without requiring GitHub sign-in.

Install this version once to enable automatic update checks on older unsigned builds. Download `PureTube_0.9.1_x64-setup.exe` below. The `.sig` and `latest.json` assets are used by the updater; `SHA256SUMS.txt` lists file checksums.
