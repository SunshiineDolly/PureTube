# PureTube releases

Windows installers are available in GitHub Releases, with one release per embedded application version. The newest version is marked Latest. Verify downloads using each release's SHA256SUMS.txt.

The main branch contains the current source. Source snapshots are retained for every release from 0.9.0 onward, plus 0.1.1 and 0.1.2. Other historical tags contain archival release metadata only; their automatically generated GitHub source archives do not contain application source. Their original Windows installers remain available as release assets.

Releases from 0.9.1 onward include signed update artifacts. Older builds need one manual installation of an updater-enabled release. Future signed updates can be installed in Settings without a GitHub login.
