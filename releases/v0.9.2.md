Signed Windows update for PureTube 0.9.1 and later updater-enabled builds.

- Checks for new versions automatically on launch and every six hours.
- Settings shows the installed version, last check, release notes, and download progress.
- Update and restart verifies the release signature, installs it, and reopens one PureTube window.
- Local follows, favorites, watch-later videos, collections, profile, and preferences are preserved.

If you are using 0.9.0 or earlier, install `PureTube_0.9.2_x64-setup.exe` once to enable future in-app updates. GitHub sign-in is not required in PureTube.

The `.sig` and `latest.json` assets are for the updater. Use `SHA256SUMS.txt` to verify a manual download.
