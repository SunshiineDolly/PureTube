# Viddy 0.14.0

- Fixed failed downloads by checking stream availability and allowing compatible audio/video formats to be merged into MP4. Fragment downloads run in parallel with less frequent progress updates.
- Added Random watch to Home, Discover, and Following. Home favors your interests, Discover balances topics, and Following chooses only from channels you follow, balancing creators and favoring unwatched picks.
- Simplified the mini-player return control to an arrow with a tooltip.
- Renamed Go live to Resync live to explain that it reconnects to the current stream position.
- Removed the extra Viddy progress bar and its setting; playback keeps YouTube’s regular controls.

Downloads remain subject to YouTube availability and access restrictions. Existing follows, playlists, and preferences are preserved.
